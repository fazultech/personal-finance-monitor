IMPORTANT SECURITY AND DATA NOTES
1. This starter version stores entries in this browser's localStorage only.
2. It is NOT yet connected to Google Sheets and does not synchronise across devices.
3. Do not enter real or sensitive financial data until the authenticated Google Apps Script connection is implemented and tested.
4. Do not make your Google Sheet public or place Google credentials, authorization codes, or Telegram bot tokens in this website.
5. This package contains no financial amounts copied from your planning template. The dashboard starts at zero and all records must be entered by you.

To preview
1. Extract the ZIP.
2. Open index.html in a modern browser.

To use with GitHub Pages later
1. Create or open your GitHub repository.
2. Upload index.html to the repository root.
3. Configure GitHub Pages in repository Settings > Pages.
4. The authenticated Google Sheets integration still needs to be implemented before using this for real finances.

The starter prototype includes Dashboard, Transactions, Debts & EMIs, Accounts & Savings, Budgets, Transaction History, and JSON backup/restore.
